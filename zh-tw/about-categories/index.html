經營理念
#

福裕事業股份有限公司自1978年成立以來，專注於磨床、車床、銑床等工具機的專業研發與製造，具備自行開發人機對話介面的能力。公司以自有品牌「CHEVALIER」深耕台灣市場，並積極拓展全球業務，在美國與中國大陸設立分公司，於歐洲、中東、中國大陸及南美洲等超過80個國家設有經銷據點。

2022年10月，於新任董事長林聰麟先生及總經理董上裕先生的帶領下，逐步導入優質代銷及建設業務，將「人因設計」與「精密製造」的品牌精神延伸至建設事業，透過多角化經營策略，為集團注入新動能，邁向嶄新里程碑。

工具機事業 建設事業

事業版圖
#

  • 工具機事業：自1978年創立以來，持續深耕工具機產業，專注於高智能、高精度、高品質磨床、車床、銑床等產品的研發與製造，並以CHEVALIER品牌行銷全球。
  • 建設事業：2022年起，福裕集團首次跨足房地產建設領域，規劃低碳綠建築，展現企業多元發展的決心。

團隊與組織
#

經營團隊
#

  • 林聰麟 董事長
    畢業於國立屏東科技大學森林系，2022年接任董事長，主導公司多項關鍵決策，推動組織重整與多元發展。
    • 主要經歷：清景麟集團董事長
  • 董上裕 副董事長兼總經理
    畢業於國立高雄應用科技大學工業工程與管理系，2022年接任副董事長及總經理，協助推動企業永續發展與文化傳承。
    • 主要經歷：廣上集團董事長
  • 陳世恩 公司治理主管總管理處 副總經理
    負責董事會議事及公司治理，協助營運策略規劃與執行。
    • 主要經歷：福順工業(股)公司董事長、皇鋼機械(股)公司董事
  • 張哲華 行銷處 副總經理
    負責工具機事業群盈虧，執行公司策略。
    • 主要經歷：台灣磨粒加工學會監事、台灣工具機暨零組件工業同業公會監事
  • 張明倫 行銷處美洲區 副總經理
    負責美洲區業務發展。
    • 主要經歷：福碩科技實業(股)公司董事
  • 裴于雯 財務處 副總經理
    督導公司日常營運、資金調度、財務規劃與風險管理。
    • 主要經歷：安侯建業聯合會計師事務所審計部副理、清揚國際實業(股)公司財務長
  • 馮俊超 建設事業處 副總經理
    負責建設事業群營運。
    • 主要經歷：泰嘉開發建設(股)公司副總經理、高閎耀實業股份有限公司顧問

公司組織架構
#

  • 行銷處：行銷管理課、大陸區、台灣區、歐洲區、亞太區、美洲區、CMI行銷部（美工課、行銷技術課）
  • 新產品研發處：機構開發部（機構開發一課、二課）、電控開發部（自動化開發課、AI智能開發課）、先進材料應用部（應用工程課）
  • 財務處：財務本部（稅務會計、財務出納、股務）、海外部（大陸區、美洲區）
  • 總管理處：經管、總務、資訊、人資
  • 服務部：服務課（含大陸）、國外服務課
  • 生產部：物管課（含售服倉）、資材課、生產課
  • 品保部：品保課
